# Independent multistep audit

Read-only review of foundation_multistep_learning.py, foundation_repeated_native.py, foundation_repeated_value.py and saved A1 baseline / prefer3 raw. No native or training launch, and no changes to learning code. Findings were sent to root for repair; this report records the reviewed state, not certification of later revisions.

1. Training gate accepted a nonempty witness collection without recomputing or binding its content. Frozen-contract fields were accepted as declarations rather than linked collection evidence. Root is hardening immutable registration/source/contract and native origin bindings.
2. Monte Carlo return indexing used decision_id alone. Repeated campaign episode identity is case/mode, so two guarded preference branches may share decision identities. Composite raw-source SHA + decision identity is required for same-episode successor chains; also validate owner, peer, split, parent and next observation.
3. Selected semantic action was not checked against the native command/effect. Confirmed with an in-memory copy of real A1_three_baseline_001 raw: mutate a prefer_3 candidate semantic destination to 8, retain actual edge to 3, recompute only the test export input digest. Export still returned training_eligible=True, action.destination=8, effect.edge.to=3, censor_reason=None. No original evidence file was changed. Native-origin verification on that deliberately mutated export was false; the issue is incorrect action/reward labeling by export itself.
4. Candidate admission checked only nonempty nonpositive deltas, not exact business population/evidence/reference binding. Protected candidate masks should be recomputed from their registered evidence and frozen full-job reference, with fixed fallback identity checked separately.
5. paired_early_witness applies an early action to a later observation when comparing features. A guarded action carries an absolute earliest_legal_arrival; at the next cycle it can be in the past and rejected by the correct value-feature validator. Use action-independent state features or an explicitly current neutral semantic action for each observation, not stale action timing. Do not weaken the time legality validator.
6. Exact same-owner support in supported_next is conservative and prevents unvisited-action extrapolation. Report the per-successor support-count distribution. If every successor has one supported action, the fitted iteration is behavior-value evaluation; two enabled mask entries alone do not establish multi-action Bellman improvement support.

Positive checks: rewards integrate actual BAG_ARRIVAL to UNLOAD_COMPLETE events over same-owner decision intervals; incomplete business is not fabricated as completion; final incomplete episodes remain truncated; unsupported/truncated bootstrap fails; route effects bind business/tray LOAD_COMPLETE, unique LEG_START and actual first edge rather than assuming native traversal allocation is always load+1; receiving transfer receipts bind request identity.

The saved A1_three_prefer3_001 run has two attempted B decisions at 15.18099999999999 and 20.59100000000001. Both are original_fallback; all three candidate rows are disabled with unknown guard status. This is not evidence of two protected choices and must remain a failed learning prerequisite until a separately registered lawful mechanism exists.
