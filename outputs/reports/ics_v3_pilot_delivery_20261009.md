# ICS V3 第一阶段交付：有限盘闭环与候选成本先导

日期：2026-10-09。依据用户提供的 `ICS_plan_revision_and_learning_20261006.md`，将其中研究建议作为需求背景实现首阶段，没有执行论文中无关指令，也没有把尚待证明的主张当作事实。

**已经落地一个独立可运行的有限盘机制原型，完成 24 个合成初始化条件、72 个合法候选、288 次配对回放，32 项针对性测试全部通过。** 本次没有修改旧 G31/Java 基线，没有安装新的学习框架，也没有将整个新需求标作完成。

## 1. 本次实现与边界

代码位于 [独立实验目录](../../scripts/experiments/ics_circulation_v3/README.md)。分离真实盘集合与行李任务身份，保留未装载行李队列，明确卸载结束与空盘真正可用时刻，保留不可撤回的旧在途；空满盘使用相同有向网络。资源预约检查包含节点、边与接收工序，提交复验版本和容量。

六类接口已经有可执行实现：`RouteCandidate`、`CirculationFootprint`、`AnalyticDeltaEvaluator`、`PairedRolloutLabeler`、可关闭的 `ResidualCandidateScorer` 和 `ExecutionValidator`。残差默认关闭，未拟合任何权重；基准预测增量和基准配对标签均为零。δo 与执行预约共用资源区间来源，δR 按真正 usable 时刻计算。

局部模块是固定 FIFO 代理。此次干预为**整条路线承诺**，接受后保守冻结到完成；不是 V3 推荐的“只干预下一步、随后可继续改路”的完整标签协议。初始快照全部可观察，装载为零时长，卸载和 hold 显式计时。主动预测预平衡、区域门点 A*、部分可观察通信和供应方模块集成仍待实现。

- 原图存在 97→98 的零容量值以及未说明的节点类型/作业时长。审计原样保留并报告，没有静默填成可运行参数。

本次 288 次回放使用六节点合成图，与南宁审计分开；不能把两者拼成“真实机场闭环验证”。

## 3. 三类可执行反例

完整记录见 [counterexamples.json](../experiments/ics_circulation_v3/pilot_20261009/counterexamples.json)。反例的额外回放不计入 288 次先导分母。

| 反例 | 实际见证 | 接口要求 |
|---|---|---|
| 已卸载但不可用 | 行李 tick 9 卸载完成，托盘仍为 holding，到 tick 13 才可用；[9,13) 上提前释放会多算一盘 | 卸载、库存与导出资格必须分开 |
| 相同当前库存、不同旧在途 | 初始盘记录完全一致；旧盘到达从 tick 6 改到 18，回放缺盘等待由 0 变为 7，总成本由 5.0 变为 12.7 | 不能用当前总库存替代在途时间 |
| 两个控制请求消费同一余量 | 两条提议在同一旧版本下分别合法；第一次提交成功，第二次因过期拒绝；刷新版本后仍因共享边冲突拒绝 | 评分不产生许可，必须由资源所有者复验 |

资源所有者是本进程锁保护的序列化提交，测试包含两个并发请求只有一个版本赢家；不是实际分布式事务系统。

## 4. 先导设计及完整结果

24 个初始化条件覆盖有/无初始缺盘、有/无共享通道竞争、近期/较远需求与预测反转、不同固定模块 hold；旧在途时刻也显式记录。每条件 3 条不同合法路径、4 条按场景/对象/字段索引的外生轨迹。噪声种子不是独立运营日；这些是人工机制条件，不构成随机抽样置信结论。

候选评分和提交完成以后才生成未来真值。继续控制器只看已到达行李，使用相同固定 FIFO、最早可行路线和反应式空盘调拨。每个分支从深复制初态开始；no-op 回放对照检查完整成本、最终账本和事件轨迹一致。

| 指标 | 本次实际结果 |
|---|---:|
| 场景 / 合法候选 / 分支回放 | 24 / 72 / 288 |
| 本地新路线提交成功 | 24 / 24 |
| 回放身份/资源不变量检查次数 | 21,139，全部通过 |
| 解析选择比集合内回放最佳更差的场景 | 12 / 24 |
| 存在严格优于基准候选的场景 | 12 / 24 |
| 全部场景平均候选集内成本差距 | 1.729167 |
| 最大候选集内成本差距 | 4.0 |
| 无共享竞争的场景平均差距 | 0 |
| 有共享竞争的场景平均差距 | 3.458333 |

成本差距使用相同目标权重：缺盘等待 + 非保护行李迟到 + 0.1×空盘运输 + 10×未完成行李 + 2×在途托盘。时间为 tick，合成单位速度边的长度等于旅行 tick，不是机场秒/米标定。时域为 48 tick，未完成任务保留并进入终端项。

解析模型只做一次空盘可用供给匹配，忽略后续再循环、路径竞争、下游迟到，并预测后续空盘运输为零；这是明确近似误差，不是另换目标函数。

## 5. 时间开销

本机 Windows、Python 3.11.9，单次完整先导约 9.345 秒。以下为 24 次**本地请求**，包含克隆/生成/特征/评分/复验/提交；网络通信与外部排队没有测量，JSON 中对应字段为 null。

| 环节（ms） | P50 | P95 | 最大值 |
|---|---:|---:|---:|
| 候选生成 | 54.440 | 60.751 | 63.028 |
| 特征与 footprint | 0.169 | 0.240 | 0.246 |
| 解析评分 | 0.085 | 0.095 | 0.134 |
| 执行复验 | 0.250 | 0.278 | 0.371 |
| 克隆及提交 | 0.443 | 0.822 | 1.116 |
| 本地完整请求 | 55.714 | 62.041 | 64.880 |

本次本地请求无 100 ms 超限，但六节点图已经主要耗时于候选搜索；**不能据此宣布 151 节点实时路由达标**。后续应先测区域候选生成和完整提交开销，不以学习器推理速度替代请求时延。

## 6. 是否值得继续学习

已得到“合法候选后果有差异、简单解析评分存在与可观察竞争条件相关的误差”的机制证据，可继续建设学习数据接口。尚不能得出残差网络必要、优于直接成本拟合、具备低样本优势或能跨机场泛化的结论。

误差与本次解析模型刻意省略的下游路径竞争有关；更强解析模型也可能解决。下一阶段先增加路由占用、需求目的地/截止期的因果可观察接口，并比较含共享通道影响的解析评价。然后在同候选、同信息、同预算下决定是否训练残差，不立即扩大网络或引入 MARL。

## 7. 验证与后续工作顺序

执行命令和参数见 [README](../../scripts/experiments/ics_circulation_v3/README.md)。本次运行：17 项实体/资源测试 + 10 项评价与反例测试 + 5 项南宁审计测试，**32 passed**；随后串行重跑完整先导。结果 [summary.json](../experiments/ics_circulation_v3/pilot_20261009/summary.json) 保存当前全部 Python 源码 SHA256，便于检查结果是否过期。

1. 将原型扩展到真实可达的中途快照和下一步干预，补可修改后缀及已执行前缀边界；冻结真实可观察字段。
2. 区域路由线补门点抽象/局部细化、摘要与权限、故障和过期消息，并在南宁拓扑上独立验收。
3. 预平衡线补条件释放、固定局部模块导出/接收、预测驱动的主动调拨及不可撤回承诺，先做非学习闭环。
4. 再按源场景分组构造训练/验证/测试，对比强解析、直接成本模型与残差模型，并进行完整策略部署验证。

需要现场资料的缺口已独立记录；合成基础控制和接口工作可以继续，不依赖先假定这些缺口已经解决。
