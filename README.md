# ICS Simulation

Airport baggage handling system simulation project associated with a CIE manuscript.

## Project layout

- `src/` - Java source code.
- `bin/` - Existing compiled Eclipse output from the original project.
- `Java_jar/` - Bundled third-party jar dependencies.
- `example1/`, `task/`, `map2.txt`, `inputdata.txt` - Simulation input data and examples.
- `images/` - GUI assets.

## Entry point

The main entry point is `src/RUN/Main.java`.

This repository preserves the original Eclipse-style project structure, including `.project`, `.classpath`, and `.settings/`.
