## THT、TH 与资格

主 THT 为每件原始袋的 **`Σ段(完成时刻 − 共同 canonical scheduled release D)`**，再在完整原始袋人口上取 min/mean/max；P95/P99 是增加的尾部统计。它包含各段从 D 到入网的等待，按段求和，不等于第一次 raw entry 到最终完成的整段历时，也不额外把 EBS 两段之间的储存间隔重复加入 THT。原始 shared-D 科目的 D 取其已核验历史 schedule。

次要 THT 使用各方法原生 admission/processed-attempt 时钟，单独标为入网或原生处理起点后的段和时间。**HCA 的整数 `release_epoch` 与 canonical D 明确区分**：主列重算 `finish − canonical D`，另存整数释放偏移；不能因为主列统一了统计起点，就声称各执行器实际释放量化或 admission 事件具有完全相同的物理定义。[导出实现](../../scripts/eval/export_feng_v5_campaign.py)保留两组字段，不能跨时钟挑选较好的一列。

**TH 在本 campaign 指共同绝对终止 epoch 98,259 秒前完成的原始袋数**，不指运输段数、准时袋数或每小时传送带容量。完整提前结束的 1× 科目若全部完成，则 TH 相同，较短 THT 表示更快完成运输，不自动意味着此固定人口下 TH 更高。可选小时归一化为 `完成袋数 × 3600 / 98259`，其分母从模型时间零起算，不能冒充有效营业窗口速率或最大系统容量。准时率以全部原始袋为分母；完成率、未完成数、迟到下界与积压面积分别报告。源积压截至所有段都已入网，因此包含 EBS 计划等待，不能解释为纯装载口物理队列面积。

**2× 的正式 THT min/mean/P95/P99/max 始终 N/A；其他负载只要全人口未完成也为 N/A。** 缺失值在图表中明确显示，不能画成零或使用完成袋子集补值。clean DEADLOCK/HORIZON_REACHED 可以是有效实验结果，未完成袋保留到固定时域计算业务指标。campaign 的 180 格完成归档与每格袋人口全部完成是两件事。

十种子汇总以种子为配对单位；某项缺任一个有效配对种子就不给可用子集估计。导出的“平均 THT 均值”是十个种子各自全人口均值的平均；同理，P95/P99/max 的跨种子平均不是把十个种子的所有袋混池后重新求分位数或最大值。CI 为配对种子 bootstrap；胜/平/负以表中 reference 方法为方向。THT 优势随地图、负载与时钟限定，并与完成量、准时率和积压代价同时解释，不写成所有指标全面胜利。

## 最终报告随结果保留的证据限定

- **HCA 历史构建记录缺口：** 新 campaign 的 HCA 控制来自旧实际运行及逐格输入/原生证据复核；当时没有 source/class SHA，不能用当前 build 补成历史执行身份。它们与原始 shared-D 表里的历史工作簿 HCA 也不是同一批运行。
- **G31 证据层级：** 新随机 campaign 的旧控制 JSON 保留二进制/canonical 身份、聚合值和当时完整性门；没有保留下来的全量逐袋 payload，不能声称现归档可逐袋重做这些 G31 控制。原始 shared-D 的新 G31 重跑已另存完整终态 payload，不能用它补齐所有旧控制格。
- **V5 与归档核验：** trace=0 保存全部袋、段、计数与身份，支持生命周期和指标复算；不能独立证明每 tick 无碰撞或服务只启动一次。相关性质引用单独回归证据；archive PASS 表示其已实现的身份/复算检查通过，不等于重新执行全部模拟。
- **出版版本：** 学位论文、CIE 37 页一审修订稿及回复已阅读；正式论文题名、卷期和 DOI 已确认，但正式全文未取得，DH 步骤及 Table 4 仍未作 publisher-final 对照。[正式出版补充记录](feng_cie_published_version_lookup_20260905.md)。不能写成“正式发表全文已逐项复现”。
- **墙钟：** 新 V5 与历史控制的原记录来自不同时间和并发条件，保留为运行记录；不能直接作受控速度比，也不能把 DH tick 重试请求数与 G31 junction 决策数当成等价操作数。
