# DH post-movement scoring V6: pre-result contract, 2026-09-05

This contract was written before implementing V6 and before any V6 full-population result. The primary motivation is Feng's stated sequence of position/state update (a), then outgoing-route scoring (b), then stopped-outlet handling (c). The source wording supports testing the updated movement state in scoring, while exact global phases versus per-bag traversal remain unidentified. V6 tests one explicit global-phase interpretation; it does not claim to recover source-exact execution.

V6 is derived only from the frozen off-edge-overlap control. After its first internal movement plan, construct a separate immutable scoring view. For each existing edge occupant:

1. Omit bags whose upstream departure is already guaranteed independently of route choice: goal completion, expiring positive-through service, or granted zero-through completion.
2. Copy the planned position of every remaining occupant. Mark it MOVING if that position advances during this tick; otherwise mark it STOPPED. This includes an already-at-boundary bag that remains stationary and a newly stopped or newly restarted interior bag. A bag that just advances to the final cell is still MOVING for this phase.
3. Keep source induction and off-edge transfer/HOLD bags outside edge counts, exactly as in the parent space model. Do not add this tick's newly approved target-edge entrants to the scoring view.
4. Use this single frozen view for every route score in this tick. Keep the original physical occupancy, original bag statuses, FIFO keys, node-service grant rules and target-edge entry checks unchanged until their normal commit.

The moving/stopped penalty refers here to the output state of phase (a), not cumulative stopped counters or whether a timer makes logical progress. A positive node-through timer can advance while its physical bag remains stopped. The paper does not disclose the reconstructed off-edge timer state; including such bags in stopped penalties would be a separate space/visibility hypothesis. Since current route costs count bags over whole edges, an interior position change affects these costs through the MOVING/STOPPED label, not through a continuous distance-to-node term.

In the control, all outgoing entry requests are from off-edge bags (`upstreamEdgeId=-1`). Thus route choice cannot create another upstream departure in the same tick. All guaranteed departures are known before scoring. V6 will assert that the final guaranteed-departure set equals the one used to form the scoring view and that the final movement plan equals the first plan. It will reject a physical edge-entry proposal rather than silently extending this proof to a retained-boundary executor. No fixed-point iteration or re-scoring after admission is introduced. Graph cycles therefore do not create a within-tick dependency cycle in this probe.

Meaningful fixtures must show an actual selected-exit change against the parent's counterfactual in a newly stopped case and a newly restarted case; verify guaranteed goal/zero/positive service departures are excluded; keep same-tick entrants invisible to other current requests; preserve a stopped entrance's original admission blocking even when it moves in the scoring view; and preserve single-bag zero/positive free-flow times. Record the first differing decision tick, selected edge, candidate count/score evidence and complete traces. Per-tick no-feedback assertions remain active in formal execution. Policy coefficients, candidate routes, source/goal timing, 1-second through, 2-second overlapping transfer and all population inputs stay frozen.

Use the original control as the sole parent. Do not automatically apply this view to V2 or V5, where physical departure mechanisms differ. The full map2 experiment is left to the main task after source and fixtures freeze. Preserve all 28,506 raw bags and 43,603 legs and report the same shared-D sum-of-leg THT and distributions under the current [acceptance clarification](feng_dh_map2_acceptance_update_20260905.md). Neither historical mean closeness nor another algorithm's ranking selects this interpretation.
