## 3. 两份 CIE 作者稿不能混为同一对照表

**F0 第 22 页 Table 3 的对照是 Manufacturer，不是 DH。** 旧稿明确称真实行李运行数据暂不可得，使用 BHS 厂商提供的仿真结果，且寻路细节受保密协议限制。该表 Manufacturer 为 4.56 / 5.78 / 18.01 分钟，IoT-DRPA 为 3.13 / 3.96 / 5.98，改善 31.4% / 31.5% / 66.7%。

F2 第 25–26 页新增自己的 DH 仿真说明并以 DH 替换上述对照；F1 与这个 DH 表相同。因此，“另一 baseline”若指旧稿厂商算法，不能把新实现的 Tarău DH、静态 A* 或 LRA* 改称厂商算法；若指 LRA*，它在论文中属于实时速度偏差实验，不能由无故障三负载矩阵代替。原始 Tarău 方法与 Feng 简化 DH 也应保留各自方法身份；本审计不据文献同源认定二者实现相同。

## 4. THT、TH 与 deadline：哪些对应已经证明

F2 第 14 页及 F1d P123 明确任务元组中 `t_k` 是进入系统时间、`τ_k` 是航班出发时间；F2 第 15 页及 F1d P130 以所有托运行李平均输送时间为目标。F2 第 24 页 / F1d P218 将 THT 称为行李 throughput time，将 TH 定义为给定时段 T 内处理量；论文主要展示 THT，称 TH 可由运行到 T 后计数获得。F2 第 18 页还明确：规划失败的任务在连接线等待下个规划周期，例如 1 秒后重试。

这些直接支持“时间指标、固定时段完成量、可能存在源端等待”等概念，但**正文没有给出从作者原始日志字段到 THT 的完整可执行公式**。不能仅凭名称证明当前 canonical scheduled D、首次 admission、HCA 成功 planning 后 processed 时间都等于论文同一个物理入网事件，也不能认定 EBS 两段之和和储存时间处理已经逐字复现。

当前合同的 `THT(D)=Σ段(E−canonical scheduled D)` 是明确操作定义；native 表另用各方法 admission / processed 起点。十种子汇总是先求每种子全人口统计再汇总，配对 bootstrap 的采样单位也是种子；原论文表描述所有行李的 min / average / max，没有披露这个十种子层级。当前 2× 一律正式 THT N/A、其他组缺全人口资格则 N/A，是防止幸存者偏差的扩展协议规则，不是原论文原有的 2× 规则。

**准时率与论文故障 success rate 目前不能直接等同：**

- F2 第 29 页 / F1 第 45 / 31 页、P238 要求到卸载站不晚于航班起飞前 45 分钟，否则失败；分母为所有行李。
- 原 Java [Main.java](../../legacy/jichang_origin_readonly/src/RUN/Main.java) 第 108 行将输入第三列直接赋给 `STD`，第 123 行将 EBS 出库计划时刻设为 `STD−2700`。原 `inputdata.txt` 表头仅写 `STD(s)`；这些读取本身不能证明该列是否已经预扣 45 分钟。
- 当前 [external 归一化](../../scripts/eval/run_cie_external_baseline_robustness.py) 第 1039、1047 行以 `task.std` 为 deadline，按最终完成不晚于它计准时。字段值的代码传递已确认；它与论文“原始航班出发时刻减 2700 秒”的业务映射尚未独立证实。若输入 STD 确为未扣减的航班出发，则两条截止规则相差 45 分钟；这是条件判断，不能据此擅自修正已冻结数据或宣告已证双扣 / 漏扣。

论文的单次寻路计算时间小于 1 秒（F2 第 24–25 页 / F1d P219）也不是整个仿真或矩阵墙钟，不能与当前含进程启动、输出、归档及并发影响的 wall time 直接作倍数结论。

## 6. 可用于总审计的结论边界

可以说：本项目已完成按公开合同定义的两地图多负载扩展比较，保留不利 native 时钟结果、未完成及 N/A；也保留过往相邻实验科目。可以说：原文直接支持 DH 的 0.2 秒逐袋更新、全最短路径上 moving / stopped 罚项、出口阻塞时等待等部分机制。

不能说：所有现有外部方法已逐项复现冯论文整套实验、三负载等于论文四速度、到达抖动等于实时 IoT 动态策略、旧 no-A* / G31 内部消融就是外部 LRA* 或厂商算法、当前准时率已证明等同论文提前 45 分钟的故障成功率，或当前两个 THT 起点已证明等同出版社原始日志时钟。尚未证实的映射在本次记录为边界，不修改既有数值，也不根据目标排名增设参数或实验资格。
