# 发布整理记录

本目录的生成属于证据整理，不是新的物理实验、查询或回归测试，不改写各轮封存资源账。

首次选择规则把未含 `roundN` 的 Phase4 目录分组名写为 `legacy_rounds01_to07`。检查发现部分未编号目录也属于较晚轮次，这个组名可能误导。构建在扫描期间中止，当时尚未创建 `receipts/` 或 `inventory/`，未复制或修改任何实验原件；改为中性的 `phase4_unnumbered_series` 后重新开始。首次扫描、选择、阅读和中止的 CPU 未完整测量，保留为未知辅助开销。

最终构建计量只覆盖 `manifest.json` 标明的哈希与复制过程；不包括此前枚举、后续文档、链接和打包检查。所有 TSV 只标记打包时实际存在的文件，没有将未随仓库发布等同于本地缺失。
