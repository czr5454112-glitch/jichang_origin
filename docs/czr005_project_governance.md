# CZR005 Project Governance

## Fixed Real Topology Rule

The current airport map is treated as the real ICS topology for this project stage.
Do not generate or substitute synthetic topologies for main claims.
All main high-flow experiments must keep the official real map unchanged.

## Original ICS Data Generation Rule

Large-scale simulation task streams must be generated by learning and reproducing the original ICS project's data-generation rules.

Primary original project path on the user's machine:

`C:\STUDY\民航二所项目相关\冯汝琛相关材料\冯汝琛相关材料\ICS项目`

Codex must inspect the original ICS project before producing high-flow task streams.
Do not invent arbitrary flow scaling, random OD generation, random pass_time generation, or random fault/repair schedules for main claims.

If the original ICS project path is unavailable in the current environment, Codex must block main-claim data generation and produce an access-missing audit instead.

## Data Claim Levels

High-flow data must be labeled with one of:

- `original_project_generated`: produced directly by the original ICS project generator or simulator.
- `original_rule_replay`: generated by a reimplementation after auditing original project rules.
- `distribution_preserving_resample`: generated by resampling original data while preserving documented OD/time/source/goal distributions.
- `diagnostic_synthetic_only`: artificial stress data for debugging only; not allowed for main performance claims.
