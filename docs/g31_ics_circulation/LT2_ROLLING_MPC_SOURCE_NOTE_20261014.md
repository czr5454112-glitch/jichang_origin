# 滚动模型与温启动的来源边界

2026-10-14查阅原始作者报告：A. N. Tarău、B. De Schutter、H. Hellendoorn，*Predictive Control for Baggage Handling Systems Using Mixed Integer Linear Programming*，MCPL 2010，16–21页，[作者全文](https://www.dcsc.tudelft.nl/~bdeschutter/pub/rep/10_041.pdf)，[DOI](https://doi.org/10.3182/20100908-3-PT-3007.00004)。网页抓取日期不是论文发表日期。

§2.1描述先执行优化序列首动作，再依据新状态滚动求解。§3.1的简化模型允许实值垂直队列，并将需求和自由流时间按采样期处理。§4.2及案例讨论用MILP解初始化原非线性优化。其结果不能证明本项目原生离散合同下的逐件保护或完整请求100ms；温启动本身也不是本项目的新贡献。

对当前实现的具体约束来自本项目合同：后来决策必须继承已承诺的装载、占用、接收预约、边间隔和已完成义务；没有公开证据的剩余清空时间应保持未知。不能把首次决策模型换一个当前时刻后继续使用空初始日历。每次新求解应记录输入快照、决策域、计算预算、首动作和父请求，后续以真实ACK和局部新观察触发更新。比较组使用相同信息、模型、预算与继续策略，并包含普通中性平台搜索和资源修复。

上述是实现与验收要求；当前后来路线仍有手写规则，尚未完成可验证的滚动联合求解器。
