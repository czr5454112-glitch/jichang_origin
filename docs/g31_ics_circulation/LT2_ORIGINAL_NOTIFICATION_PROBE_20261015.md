# Original-input finite notification-operation probe

This experiment is prepared for the original 28,506-job, 151-node, 227-edge
input. It is not yet a native execution result or a production business-request
100 ms certificate. Native owner notifications contain a sequence, time and
change mask, but no business-request ID. The declared root is therefore an
experimental notification bundle, with explicit per-job children from the
owner's full public observation. It is different from both the earlier owner
activation upper bound and the tiny installed-operation admission contract.

The immutable domain has three communication cases: original baseline,
drop-first-ACK, and withholding the first 100 ACK packets. Each has a plain and
native025-timed arm, executed serially with a 180-second process cap per cell.
Every case retains the complete original job denominator. Only the declared
ACK-loss factor changes. No routing permission is added; the original input's
default `allow_suffix_reroute=false` is preserved. Consequently this campaign
does not exercise an original-map R1 installation permission that does not
exist in its input.

A batch is admitted before advancing native physics. Each returned owner public
update creates a bundle before its first observation; every resulting bundle
is charged the entire trigger advance. ACK/timeout-only notifications continue
existing operations and do not create independent proposal roots. The cutoff
is **12 nonempty notification boundaries**, including ACK-only boundaries,
not 12 proposal bundles or 12 jobs. After this cutoff, existing immutable
requests may finish within a 120-second logical completion tail. The limits
remain 100,000 native events per call and 20,000 calls for the finite cohort.
All later notices are recorded even when admission has stopped.

Every unique returned noncompleted job is enrolled, including handed-off and
failed jobs. Explicit public completion is recorded as an exclusion. Missing,
malformed, future, foreign or unrepresented carried contracts make scope
unknown. Empty job scope still has a bundle denominator. All children depend
on all operations created in their bundle; affected-job authority for empty
transfers and cancellations remains unverified. A later independent bundle
cannot settle an older pending request.

The proposal uses the unchanged public demand/service-publication and analytic
transfer-candidate functions. It uses only returned local observations,
delivered messages, own outbox and static public contracts. It does not call
result, checkpoint or fork endpoints. Immutable retries remain attached to the
original operation identity and bundle. A submission reply or forecast cannot
close a root. Closure requires every actual terminal ACK to be returned by a
query and processed, a complete same-time native drain, and an encoded returned
decision. Rejection, expiration and failure produce `terminal_failure`, not
successful service. Missing ACKs and incomplete native timestamps remain open.

The worker rebuilds the complete original input from its raw/map sources and
exact proxy contract before constructing native state. It requires complete
JSON structural identity with the frozen baseline, preserving list order,
before applying an ACK-loss factor. A pure rebuild check already confirms the
28,506/151/227 identity. Mandatory setup starts before this rebuild and includes
input validation, binary/ABI checks, native construction, the timing-capture
constructor and all bookkeeping through the earliest batch admission. The
whole interval is charged to every root without division or subtraction.
Python/process startup is additionally retained as a whole-worker upper bound.

Each root's outer interval includes observation, preprocessing, candidate and
codec work, fallback/retry handling, source/receiver validation, commit, ACK
processing, native advances, required drain and encoded output. Shared work is
charged in full to every overlapping root. Whole native advances remain
charged, including unlabeled remainder; logical transport delay is not
converted into CPU time. Streaming or diagnostic copying inside an open
interval remains charged. No GC or physics time is subtracted. An upper bound
above 100 ms is not itself an isolated measured latency violation. The static
input rebuild alone may make these intentionally conservative whole-setup
bounds exceed 100 ms; the experiment does not conceal that cost.

The saved-file verifier checks the exact six-cell domain, process outcomes,
input/source/binary/archive pins and every tape chunk. It replays the actual
public API transcript through the unchanged policy and ledger, consuming every
call in order, and independently checks admission, observation, immutable
payload, ACK query, drain and output references. Timed native envelopes must
match service calls one-for-one. Plain/timed comparisons include every raw
argument/public result/logical clock after removing only outer call timing,
plus policy decisions, outbox, lineage and final native seal. Missing or
inconsistent evidence returns unknown while retaining all six declared cells.

The source closure follows imports under both the repository root and `src/`,
preserving relative archive paths. The currently loaded project modules are
also checked against that inventory before and after each worker. This avoids
the two unpinned startup modules found in the older tiny probe; that historical
limitation remains documented in its separate supplement. The accepted025
timing contract remains unchanged, and no026 timing acceptance is inferred.

Implementation and pure evidence:

- `original_notification_contract.py`: admission, public job scope and closure.
- `original_notification_probe.py`: finite online engine and streamed API tape.
- `replay_original_notification_probe.py`: deterministic offline replay and clocks.
- `run_original_notification_probe.py`: full input rebuild, source closure and failure receipts.
- `verify_original_notification_probe.py`: saved-file, per-arm and cross-arm gate.
- `original_notification_pure_006.xml`: 57 passing pure tests, including outer
  lifetime clock guards. Earlier005 has 55 passes. Earlier004 retains
  sandbox temporary-directory rename denials and a fixture assertion that did
  not apply the native default for an absent routing-permission field. Workspace
  test directories and the correct default resolved those test issues.

Preparation creates no NativeSession. Execution requires a separately released
native worker slot. The prepared command and final source hashes are saved with
`original_notification_prepare_001/ready_receipt.json`: 91 source pins,
`source_changed=[]`, `actual_loaded_unarchived=[]`, plan SHA256
`f3478cb2cb3e80878e690adabf8a308eb93a103e08da8b6588cbed995ce6af2e`.
No native result is claimed by that receipt.
