# LT2 native timing sidecar streaming, 2026-10-14

Stage 1 is implemented as an opt-in diagnostic storage experiment. It streams only exported Python native timing batches and call envelopes. The production policy, native binary, owner-update denominator, coarse request ledger, all shared-cost associations, complete native charges, and required controller output remain unchanged. The paired native022 experiment below has executed. It does not establish a performance or 100 ms certificate.

The separate [driver](../../scripts/experiments/g31_ics_circulation/profile_streamed_native_timing.py) defaults to retained sidecar storage. `--stream-native-phase` selects the [streaming capture](../../scripts/experiments/g31_ics_circulation/stream_native_request_timing.py). Both arms postpone the native phase audit until all measured controller calls and the unchanged serial replay have finished; this keeps repeated validator allocations from being an extra difference between the two storage arms. Both continue the original coarse ledger analysis after each controller call.

Each exported chunk contains the original batches, original call envelopes, and captured errors, in original order. It includes the initial empty epoch-establishing batch and every cumulative identity table. Native span IDs and counters are preserved; Python call ordinals use a monotonic total independent of the current buffer length. After the complete controller output returns, native take and diagnostic writes occur outside its service window. A successful immutable chunk write and new immutable prefix manifest commit allow only those diagnostic buffers to retire. A write failure poisons the stream, retains the in-memory buffers, and leaves partial files as evidence. Prefix files are never overwritten.

A sealed manifest commits the expected total calls and batches. Its hash is saved in the final ledger and run manifest. Reconstruction requires that externally retained reference, checks every chunk hash, contiguous offsets, exact listed files, namespace, epoch and call ordinals, and passes the unchanged raw object to the existing native phase validator. An open prefix, missing final chunk, reordered/changed record, exception, overflow, or conflicting identity remains unknown. Hashes detect changes relative to a trusted reference; they do not authenticate an attacker who can replace the final reference and all evidence together.

The original coarse ledger stays in memory because later pending-owner notifications can add dependencies to earlier native/window/gap bundles. Streaming it correctly would require a separate append-only association journal and proof; it is outside stage 1. The native session also retains its physical history and identity tables, and the namespace registry retains the native session object. Consequently this change does not bound the complete diagnostic object graph and cannot promise elimination of GC pauses.

`--record-gc` registers callbacks only around each captured controller invocation and removes them in `finally`, including exceptions. Each collection saves absolute `perf_counter_ns` start/end, current owner-update root and current native method. This permits offline intersection with complete service/owner/native intervals; post-return native-export collections can be recognized from the service-window boundaries. Callbacks allocate some diagnostic objects, and their measured overhead stays in the original intervals. GC is neither disabled nor forced, and no GC time is subtracted. Window GC files are exported after measurement. Whole parent-process wall time remains in `process.json`; native export, sidecar writes, final reconstruction, and evidence I/O are reported diagnostic process work, not missing required controller work. The stream's `chunk_prepare_write_hash_ns` is only preparation/serialization/chunk-write/hash time; it excludes manifest commit, seal, reads and reconstruction and is not total diagnostic time.

The executed experiment is a serial two-arm retained-versus-streamed run with the same accepted native022 binary/archive, complete original input, controller parameters, fixed 500-activation boundaries, 5,000-activation prefix budget, and GC callbacks enabled in both arms. Each arm must match an uninstrumented serial replay in calls, decisions, native boundaries, state, outputs and native seal. Independent reconstruction and both existing validators must pass. Report every open root and all coarse upper bounds unchanged in interpretation. A lower bound or upper bound above 100 ms is not an isolated complete-request violation; whole native advances and mandatory shared output remain conservatively charged. Background simulation/build activity must be disclosed, and a concurrent run cannot establish isolated speed.

## Independent saved late002 review

The [late002 assessment](../../outputs/experiments/g31_ics_lt2_sustained_20261014/late_reconstructed_profile_002/assessment.json) reproduces the recorded prior observables and the next 2,000-update shard exactly excluding timing fields. Original hidden native-state equality remains unproven. Its cProfile run took 72.7472 s: the recent-policy native observation method accounts for 36.752 s over 2,316 calls, while deepcopy has 14.161 s cumulative time and transfer-candidate construction 9.025 s. These cumulative components overlap and must not be summed.

The saved GC file contains 4,055 collections: generation 0 totals 438.8954 ms, generation 1 totals 106.9442 ms, and generation 2 has six collections totaling 951.1051 ms, maximum 215.1708 ms. Every generation-2 collection exceeds 100 ms. Total recorded GC time is 1,496.9447 ms, about 2.06% of the profiled window. Three owner records exceed 100 ms: 241.2496, 194.4243 and 172.0808 ms. The old GC rows contain no timestamps or root context, so they cannot establish which owner overlapped a collection or which retained objects caused it. GC can explain long pauses but is not the dominant aggregate runtime in this saved profile. The profile and different GC history also prevent a direct speed comparison against the original run.
