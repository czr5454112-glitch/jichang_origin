## 与旧 R0 的历史描述，排除公平效果归因

旧 `JOINT_bridge_R0_legacy_P2201_001` 与新 C00 使用同一输入、native binary 和 controller，但 **method 与 source_bundle 不同**，且 mapping/policy_version 等记录不同。因此 `full_C00_baseline_mechanism_001.json` 显式标记 `fair_paired_effect=false`；下列是历史机制差异，不参与同源配对效果、模型晋级或 TEST 解锁。

旧 R0→新 C00 描述性变化：完成 1230→1234，按时完成 83→87，迟到完成同为 1147，过期未完成 17330→17326，J 减少 114,015.009810 bag·s。与此同时，逐件真实完成方向有 **352 件更晚、785 件更早、93 件精确相等、4 件仅新 C00 完成**；迟到幅度方向有 **334 件更坏、742 件更好**，另 4 件仅新 C00 完成形成迟到改善方向。最大已知完成推迟为 690.925854 秒。这说明总体 J 与完成计数改善不足以支持逐件无损。
