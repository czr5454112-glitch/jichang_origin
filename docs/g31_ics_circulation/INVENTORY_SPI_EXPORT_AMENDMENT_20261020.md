# 成对采集前的完整证据流式导出修订

runtime002 的旧场景 C00 已到达物理时刻 59400，但在导出完整 ACK 历史时
可用主机内存降至约 1 GB。原编码使用 `json.dumps(...).encode()`，同时
保留完整历史、完整字符串及完整字节副本；这不是新的政策效应。

尚未启动任何 runtime003 原生长分支或训练成对分支。因此保留 runtime003
及其全部未启动计划，统一改用 runtime004：在完整状态所有权优化之外，
仅将四个完整结果工件（client_calls、final_result、ack_views、
controller_final_state）逐段编码到 gzip 文件，字段、数组顺序和 JSON
字节语义不变。不删除历史，不放宽时间、事件或总预算。

纯测试核对新旧解压后的 JSON 字节完全相同，保留非有限数字报错和禁止
覆盖已有文件。仍须在同一旧场景的实际长窗口对照中核对完整物理结果与
控制器历史，通过后才能启动训练配对。该长对照使用原已分配的 reserve
名额；未启动的 runtime003 计划不占原生尝试，仍保留其审计记录。
