# 本轮文献核对与贡献边界

2026-10-22 直接核对以下原文网页；这是文献定位，不是本项目的收益证明。没有复现这些论文的实验。

| 原文 | 核对事实 | 对本项目的边界 |
| --- | --- | --- |
| [GRAND v3，V–VI 节](https://arxiv.org/html/2512.03194v3) | 学习层给出区域空闲智能体的目标分布，运输优化得到区域流量，局部匹配落实到真实智能体。 | 学习、图聚合和最小费用流的组合已有直接先例。本轮预测层只输出需求；不能把调度目标分布改称需求预测，也不能宣称组合首创。 |
| [Iglesias 等，III、IV-B 节](https://arxiv.org/html/1709.07032v1) | 需求预测进入时间展开 MPC，滚动下发首个时段任务；其仿真步长为 6 秒，MPC 周期为 5 分钟。 | 物理步长、预测分箱和优化重算可以分开。该论文不证明本 ICS 应采用 300 秒，也不授予本项目的共享通道、FIFO 或逐袋保护保证。 |
| [LaCAM 原论文摘要](https://arxiv.org/abs/2211.13432v1) | 高层搜索所有智能体位置的联合序列，低层添加位置约束。 | 本轮的站点有向图不是这种联合配置搜索，不继承其完备性结论。 |
| [Gammelli 等，GNN RL for AMoD，v2 摘要](https://arxiv.org/abs/2104.11434v2) | 使用图神经网络强化学习控制车队再平衡。 | 它支持学习调度与图结构的相关研究定位，不能作为本轮已实现 RL 需求预测的证据。 |

本轮可核验的实现工作是 ICS 适配：真实 tray 身份与来源权限、普通回流保护、统一承诺去重、软到达目标与原生出发租约分离，以及每 owner/tick 的逐盘提交。以上是对本仓库代码的描述；相对文献的方法增量仍需适配对照与消融，不能仅由场景差异推出。

原生运行闭合、代理求解可执行和服务改善分别报告。完整响应 100ms、严格逐袋无损、正式 TEST 泛化及 R1/R2 联合收益，均不能由上述论文或当前 R2 工程闭合替代验证。
