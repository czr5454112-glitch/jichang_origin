# 正式小域 FQI 原生评估：独立审计结果（2026-10-19）

**10/10 个预登记分支均闭合。三个冻结 FQI 模型被真实消费，但相对于同预算、同完整保护的强规则，逐件结果和完成时间总和均无额外改善。**

审计没有执行训练、选模或原生仿真。它只读取不可变计划、源归档、权重、
实际原生结果和进程 receipt。正式数据未用于重新选模。结果适用于两个
预登记的合成六业务父案例，不能解释为跨日、机场级或一般 RL 泛化结论。

## 模型真正参与了什么

每个 seed 在每个测试案例有两次当前评分，总计 **12 次**。独立审计重新计算
123 维合法观察特征和 64×64 网络前向值，核对全部允许候选分数、实际 chosen、
对应提交、送达 ACK 和同一 load/transport-leg 的唯一首条物理 edge。
权重文件及模型内容 SHA 与冻结选模产物一致。

- 正例两次机会分别允许 3、2 个语义候选；三个模型均以唯一最高模型分选择 8，
  与同一状态上的强规则选择相同。
- 负例第一次机会允许 default、3 两个语义候选。候选 8 的完整条件预测使
  reuse2 晚 1.3 秒，故由独立保护层拒绝，未进入模型评分。
  default 与 3 的条件完成向量相同；模型虽然唯一偏好 3，这不能证明它学会了
  在不同安全业务结果之间优化，也不能把排除有害 8 归因于模型。
- 负例第二次是另一机会，default、8 均通过保护；三个模型均选 8，与强规则一致。
- 本批没有“只剩一个允许动作”的 singleton 决策；仍逐次记录了 enabled_count。
  多个语义候选并不自动代表多个不同后果。
- 12 次模型选择中，改变同状态强规则 chosen 的次数为 **0**；
  六个模型分支对强规则的每件完成时间差均为 **0**。

因此可陈述“冻结 FQI 权重经过合法观察、保护筛选和真实原生执行闭环消费”。
不能陈述“FQI 优于强规则”“模型学会了全部安全约束”或“本测试证明长期策略额外收益”。
当前完整条件预测/保护所需计算也没有被模型替代，未证明推理节省总执行成本。
