## 离线核查

建议解压到短路径（例如 `C:/review/`），避免 Windows 的深目录长度限制。以 Python 3.11 或更新版本运行独立标准库核查器；它不训练、不启动原生仿真、不修改原证据：

```powershell
python repo/docs/external_review/g31_foundation_20261017/verify_offline_evidence.py --root repo
```

原始 JSON 中的 `C:/PROGRAMING/...` 路径属于当时运行的身份记录，保持原样。核查器将明确的仓库根前缀映射到包内相对位置，并校验原始文件哈希；不要搜索替换原件路径，否则会破坏证据。保存模型的推理重放与重新训练不应混为一谈，亦不能把旧三场景当新独立数据。
